Gemini usage limits in Chrome

Leeway shows your Gemini current-usage and weekly numbers — used or left, with reset times — in a popup, the toolbar badge and an always-on-top overlay, alongside Claude and ChatGPT.

Add to Chrome — free Source on GitHub

The honest part first

Gemini is the awkward one of the three. Claude and ChatGPT both have a usage endpoint Leeway can read in the background, so nothing needs to stay open. Gemini has none. The numbers exist only on the gemini.google.com/usage page itself, so that page has to be open for Leeway to read them.

Leeway makes that as painless as it can:

  • The popup's Gemini usage button opens that page — or switches to it if it is already open — and reads it once it has loaded.
  • Leeway keeps the tab from being unloaded by Chrome's memory saver.
  • When the tab sits in the background with numbers more than five minutes old, or Chrome has put it to sleep, Leeway reloads it quietly — and never while you are looking at it.

These are not public, stable APIs and may change without notice.

What it shows

  • The current-usage and weekly cards from the Gemini usage page, each as a percentage with its reset time.
  • Used or left. The switch at the top of the popup turns every number — popup, overlay and toolbar badge — into the remaining percentage, and back. Used is the default.
  • A toolbar badge for whichever enabled service is closest to its limit: green with 50% or more left, orange from 20 to 49% left, red below 20% left, grey when the value is old.
  • A value that could not be read is shown as ?, never as 0% — so a stale Gemini number never pretends to be a real one.

Keep it visible while you work

Open overlay in the popup opens a small Leeway window, and its Float on top button (or Enter, right after) turns it into an always-on-top window through Chrome's Document Picture-in-Picture (Chrome 116 or later). It stays above other apps while you work, and a click collapses it to one line.

Private by design

  • Uses the Google session you are already signed in to. No sign-in, and no cookie, password or API key to paste.
  • Session tokens are never stored, logged or sent anywhere. Conversations are never read — the page script runs only on the usage screen, never on a chat page.
  • No server, no account, no analytics. Everything stays in your browser.
  • The gemini.google.com site permission is requested only when you turn Gemini on.

FAQ

Why does a Gemini tab need to be open?

Gemini has no usage endpoint to read in the background, unlike Claude and ChatGPT. The numbers exist only on the usage page, so that page has to be open.

Will Leeway reload the page while I am looking at it?

No. It reloads that tab only when the tab is in the background and its numbers are more than five minutes old, or when Chrome has put it to sleep. Never while it is in view.

Which Gemini numbers does it read?

The current-usage and weekly cards, each as a percentage with its reset time.

Do I need to paste a cookie, password or API key?

No. Leeway uses the Google session you are already signed in to in Chrome, and session tokens are never stored, logged or sent anywhere.
