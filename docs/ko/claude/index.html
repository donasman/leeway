Claude 사용량 한도를 Chrome에서 바로

Leeway는 Claude 5시간·주간 한도를 얼마나 썼는지 — 또는 얼마나 남았는지 — 팝업, 툴바 배지, 항상 위에 뜨는 오버레이로 보여줍니다. 사용량 페이지를 열 필요도, 탭을 살려 둘 필요도 없습니다.

Chrome에 추가 — 무료 GitHub 소스

Claude에서 보여주는 것

  • 5시간 한도와 주간 한도를 각각 퍼센트와 초기화 시각으로. claude.ai 사용량 페이지와 같은 숫자이며, 토큰 수를 추정한 값이 아닙니다.
  • 쓴 양 또는 남은 양. 팝업 맨 위 전환으로 팝업·오버레이·툴바 배지의 모든 숫자가 남은 퍼센트로 바뀌고 다시 돌아옵니다. 기본값은 '사용'입니다.
  • 플랜 이름(예: Max 5x)을 Claude가 알려주는 경우 함께 표시합니다.
  • 로그인 하나에 속한 모든 조직을 각각 따로 — 예를 들어 개인 플랜과 Team 워크스페이스를 자기 사용량과 함께.
  • 툴바 배지는 남은 양이 50% 이상이면 초록, 20~49%면 주황, 20% 미만이면 빨강, 값이 오래되면 회색입니다.
  • 읽지 못한 값은 ?로 표시합니다. 0%로 보여주지 않습니다.

열어 둘 탭이 없습니다

세 서비스 중 Claude가 가장 깔끔합니다. Leeway는 claude.ai의 사용량 페이지가 쓰는 것과 같은 엔드포인트에서 백그라운드로 읽기 때문에 아무것도 열어 둘 필요가 없습니다. 해당 Chrome 프로필에서 claude.ai에 로그인만 되어 있으면 됩니다. 값은 1분마다, 그리고 팝업을 열 때마다 갱신됩니다.

공개된 안정적인 API가 아니므로 예고 없이 바뀔 수 있습니다.

작업하는 동안 계속 보이게

팝업의 '오버레이 열기'로 작은 Leeway 창을 띄우고, 그 창의 '항상 위' 버튼(또는 바로 Enter)을 누르면 Chrome의 Document Picture-in-Picture로 항상 위에 뜨는 창이 됩니다(Chrome 116 이상). 다른 앱 위에 계속 남아 있고, 클릭하면 한 줄로 접힙니다.

설계부터 개인정보 보호

  • Chrome에 이미 로그인된 세션을 그대로 씁니다. 별도 로그인도, 붙여넣을 쿠키·비밀번호·API 키도 없습니다.
  • 세션 토큰을 저장하거나 기록하거나 어디로도 보내지 않습니다. 대화 내용은 읽지 않습니다 — 페이지 스크립트는 사용량 화면에서만 동작합니다.
  • 서버도, 계정도, 분석 도구도 없습니다. 모든 것이 브라우저 안에 남습니다.
  • claude.ai 사이트 권한은 Claude를 켤 때만 요청합니다.

자주 묻는 질문

Claude 사용량이 얼마나 남았는지 어떻게 보나요?

Leeway를 설치하고 팝업을 열어 Claude를 켜면 됩니다. claude.ai에 로그인된 상태라면 팝업이 5시간·주간 한도를 얼마나 썼는지와 각각 언제 초기화되는지 보여줍니다. 남은 양으로 보려면 '남음'으로 바꿉니다.

claude.ai 탭을 열어 두어야 하나요?

아닙니다. 백그라운드로 읽기 때문에 아무 탭도 열어 둘 필요가 없습니다. 해당 프로필에 로그인만 되어 있으면 됩니다.

개인 플랜과 Team 워크스페이스를 같이 볼 수 있나요?

네. 로그인 하나가 속한 조직은 각각 따로, 자기 사용량과 플랜 이름과 함께 표시됩니다. 완전히 별개인 계정은 Chrome 프로필을 하나씩 쓰면 되고, Windows에서는 선택 기능인 Leeway helper로 각 프로필이 다른 프로필의 사용량도 볼 수 있습니다.

쿠키나 비밀번호, API 키를 붙여넣어야 하나요?

아닙니다. Chrome에 이미 로그인된 세션을 그대로 쓰며, 세션 토큰은 저장·기록·전송하지 않습니다.
