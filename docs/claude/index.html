Claude usage limits in Chrome

Leeway shows how much of your Claude 5-hour and weekly limits you have used — or what is left — in a popup, the toolbar badge and an always-on-top overlay. No usage page to open, no tab to keep alive.

Add to Chrome — free Source on GitHub

What it shows for Claude

  • The 5-hour and the weekly limit, each as a percentage with its reset time — the same numbers claude.ai's usage page shows, not a token-count estimate.
  • Used or left. The switch at the top of the popup turns every number — popup, overlay and toolbar badge — into the remaining percentage, and back. Used is the default.
  • Your plan name, such as Max 5x, when Claude reports it.
  • Every organization of one sign-in — for example a personal plan and a Team workspace — listed separately with its own usage.
  • A toolbar badge: green with 50% or more left, orange from 20 to 49% left, red below 20% left, grey when the value is old.
  • A value that could not be read is shown as ?, never as 0%.

No tab to keep open

Claude is the straightforward one of the three services. Leeway reads its limits in the background from the same usage endpoint claude.ai's own usage page uses, so nothing has to stay open — you only need to be signed in to claude.ai in that Chrome profile. Values refresh every minute and whenever you open the popup.

This is not a public, stable API and may change without notice.

Keep it visible while you work

Open overlay in the popup opens a small Leeway window, and its Float on top button (or Enter, right after) turns it into an always-on-top window through Chrome's Document Picture-in-Picture (Chrome 116 or later). It stays above other apps while you work, and a click collapses it to one line.

Private by design

  • Uses the session you are already signed in to. No sign-in, and no cookie, password or API key to paste.
  • Session tokens are never stored, logged or sent anywhere. Conversations are never read — the page script runs only on a usage screen.
  • No server, no account, no analytics. Everything stays in your browser.
  • The claude.ai site permission is requested only when you turn Claude on.

FAQ

How do I see how much of my Claude usage limit is left?

Install Leeway, open its popup and turn on Claude. While you are signed in to claude.ai in Chrome, the popup shows how much of your 5-hour and weekly limits you have used and when each resets, and the toolbar badge shows the service closest to its limit. Switch the popup to Left to see the remaining percentage instead.

Does a claude.ai tab need to be open?

No. Leeway reads the limits in the background, so nothing has to stay open. You only need to be signed in to claude.ai in that Chrome profile.

I have a personal plan and a Team workspace. Can I see both?

Yes. Every organization that one claude.ai sign-in belongs to is listed separately with its own usage and plan name. For genuinely separate accounts, sign in to each in its own Chrome profile; on Windows the optional, experimental Leeway helper lets every profile show the others' usage.

Do I need to paste a cookie, password or API key?

No. Leeway uses the session you are already signed in to in Chrome, and session tokens are never stored, logged or sent anywhere.
